FormPilot+ 表单记忆助手 隐私政策

最后更新日期：2026年7月30日

English version is provided below. / 英文版本见下文。

一、产品说明

FormPilot+ 表单记忆助手（以下简称「本扩展」）是一款 Chrome 浏览器扩展， 用于帮助用户在本地保存、编辑和管理网页表单填写内容，并在用户主动操作时回填到表单中。 本扩展提供多配置、多页面管理，并支持普通网页、iframe、嵌套 iframe 及 open Shadow DOM 等结构。 本扩展还提供内置演示页面，供安装后快速体验功能。

二、我们收集哪些数据

本扩展不会在后台自动采集您的浏览历史、账号体系信息或与填表无关的网页内容， 也不会将数据上传到开发者服务器。

仅当您在扩展中主动执行以下操作时，相关数据才会被写入浏览器本地存储（chrome.storage.local）：

  • 点击「保存到当前页面」或类似保存操作；
  • 在配置管理页手工添加、编辑或删除字段；
  • 导入您选择的 JSON 配置文件；
  • 切换界面语言、当前配置或当前页面。

上述本地保存的数据可能包括：配置名称、页面名称、字段标签、字段标识、字段内容， 以及您在该网页表单中填写过的文本、选项或勾选状态。 若您在表单中填写了姓名、电话、邮箱、地址等信息，或保存了含密码框在内的字段， 这些内容也可能随您的保存操作一并保存在本地。

本扩展不会主动读取剪贴板、不会记录鼠标轨迹或键盘输入日志，也不会建立用户画像。

三、数据如何使用

本地保存的数据仅用于实现本扩展的核心功能，包括：

  • 保存与编辑您创建的表单配置；
  • 在您点击「载入当前页面」或输入框旁图标菜单时，回填对应字段；
  • 在配置页展示、导出、导入您的配置；
  • 记住界面语言与当前选中的配置/页面。

我们不会将上述数据用于广告、信用评估、用户行为分析，或与填表记忆无关的其他目的。

四、数据存储与保留

数据默认保存在您设备上的 Chrome 本地存储中，由您的浏览器管理。 数据保留时间取决于您是否继续保留相应配置，或是否卸载扩展、清除扩展数据。

五、数据共享与出售

我们不会出售、出租、交易或以其他方式向第三方共享您的数据。 导入/导出功能由您在本地自行完成；若您将导出的文件发送给他人，由您自行负责。

六、权限说明

为实现上述功能，本扩展可能申请以下权限：

  • storage： 在本地保存配置、页面、字段内容、语言偏好及当前选中项。
  • tabs： 识别当前活动标签页，向该页发送保存/载入指令，并打开配置页或内置演示页。
  • webNavigation： 获取当前标签页中的 iframe 列表，以便在多层框架页面中保存或回填表单字段。 本权限不用于记录您的浏览历史。
  • 网页访问（content_scripts，含 http / https / file）： 在您访问的网页中识别可填写的表单控件，显示输入框旁图标，并在您主动保存或载入时读写相应字段。 若您需要在本地 HTML 文件（file://）上使用，需在扩展详情中开启「允许访问文件网址」。

七、远程代码

本扩展不使用远程代码。 所有 JavaScript 均打包在扩展程序内，不从外部服务器加载或执行脚本。

八、您的控制权

您可以随时：

  • 在「管理配置」页面查看、修改、删除配置、页面或字段；
  • 导出或导入本地配置；
  • 在 Chrome 扩展管理页清除本扩展数据；
  • 卸载本扩展以删除本地保存的数据。

九、儿童隐私

本扩展并非面向 13 岁以下儿童设计，也不会故意收集儿童个人信息。

FormPilot+ Form Assistant — Privacy Policy

Last updated: July 30, 2026

1. About the product

FormPilot+ Form Assistant (the “Extension”) is a Chrome extension that helps you save, edit, and manage form field values locally, and fill them back into web forms when you explicitly request it. It supports multiple profiles and pages, and works on normal pages, iframes, nested iframes, and open Shadow DOM. A built-in demo page is included for quick onboarding.

2. What data we collect

The Extension does not automatically collect your browsing history, account credentials, or unrelated page content in the background, and does not upload data to the developer’s servers.

Data is written to local browser storage (chrome.storage.local) only when you actively perform actions such as:

  • Clicking “Save to current page” or similar save actions;
  • Manually adding, editing, or deleting fields in the settings page;
  • Importing a JSON configuration file you choose;
  • Switching UI language or the active profile/page.

Locally stored data may include profile names, page names, field labels, field keys, field values, and text/selection/checkbox states from forms you saved. If you save forms containing names, phone numbers, emails, addresses, or password fields, those values may also be stored locally as part of your saved configuration.

We do not read your clipboard, log keystrokes or mouse activity, or build user profiles.

3. How data is used

Locally stored data is used only to provide core Extension features, including:

  • Saving and editing your form configurations;
  • Filling fields when you click “Load current page” or use the per-field icon menu;
  • Displaying, exporting, and importing your configurations;
  • Remembering UI language and the active profile/page.

We do not use this data for advertising, credit decisions, behavioral analytics, or purposes unrelated to form memory and refill.

4. Storage and retention

Data is stored locally on your device via Chrome storage APIs and retained until you delete configurations, clear Extension data, or uninstall the Extension.

5. Sharing and sale of data

We do not sell, rent, trade, or share your data with third parties. Import/export is performed locally by you; if you share an exported file with others, you are responsible for that sharing.

6. Permissions

The Extension may request the following permissions:

  • storage: Save profiles, pages, field values, language preference, and active selections locally.
  • tabs: Identify the active tab, send save/load commands, and open the settings or demo page.
  • webNavigation: List iframes in the active tab so save/load can work across nested frames. This is not used to record browsing history.
  • Website access (content_scripts on http / https / file): Detect fillable form controls, show icons beside inputs, and read/write field values when you explicitly save or load. For local HTML files (file://), enable “Allow access to file URLs” in the Extension details page.

7. Remote code

The Extension does not use remote code. All JavaScript is bundled inside the Extension package.

8. Your controls

You can at any time:

  • View, edit, or delete profiles, pages, and fields in Manage settings;
  • Export or import local configurations;
  • Clear Extension data in Chrome’s extension management page;
  • Uninstall the Extension to remove locally stored data.

9. Children’s privacy

The Extension is not directed to children under 13, and we do not knowingly collect children’s personal information.

10. Policy updates

We may update this Privacy Policy from time to time. The “Last updated” date on this page will be revised accordingly. Material changes may also be noted in the store listing.
