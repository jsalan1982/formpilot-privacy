FormPilot+ 智能表单助手 隐私政策

最后更新日期：2026年7月30日

一、产品说明

FormPilot+ 智能表单助手是一款网页表单记忆与自动填充工具， 用于帮助用户保存、管理和恢复网页表单中的自定义填写内容。

二、我们收集的数据

本扩展不会主动收集用户的个人信息、浏览历史、账号密码或网页内容。

当用户主动使用“保存表单”“保存到当前页面”“手动添加字段”等功能时， 扩展会保存用户主动填写或配置的表单字段内容、字段标识、页面配置和插件设置。

三、数据的使用方式

保存的数据仅用于实现以下功能：

  • 保存用户创建的表单模板；
  • 在用户主动操作时恢复网页表单内容；
  • 为输入框提供快捷填充候选项；
  • 管理插件配置、页面配置和字段规则。

四、数据存储位置

FormPilot+ 默认将数据保存在用户本地浏览器存储中。 数据不会上传到开发者服务器，也不会出售、出租或分享给第三方。

五、数据共享

我们不会将用户数据出售、出租、转让或分享给任何第三方。

六、权限说明

FormPilot+ 可能需要以下浏览器权限：

  • storage： 用于在本地保存用户创建的表单配置、模板数据和插件设置。
  • host permissions / all_urls： 用于在用户访问的网页中识别表单输入框，并提供保存、匹配和自动填充功能。
  • tabs： 用于在用户主动操作时获取当前标签页信息，例如保存当前页面或打开测试页面。
  • webNavigation： 用于监听页面加载状态，以支持 iframe 等复杂网页结构下的表单识别。

七、远程代码

FormPilot+ 不使用远程代码。 所有 JavaScript 代码均包含在扩展程序包内。

八、用户控制

用户可以在扩展的配置管理页面中查看、修改、导出、导入或删除自己保存的配置数据。 用户也可以通过卸载扩展来移除本地保存的数据。
